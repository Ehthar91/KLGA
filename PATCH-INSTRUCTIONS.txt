KLGA STOP-AND-RESUME SESSION PATCH

Replace:
- app.js
- firebase-app.js
- index.html
- styles.css

New behavior:
- Teacher clicks End -> active student tests stop immediately.
- Current test progress is saved to Firebase.
- Student sees that the session ended and that progress was saved.
- Teacher can Start the same session later.
- Student rejoins and is approved normally.
- KLGA detects saved progress and offers Resume Test.
- The student continues at the same question/progress point.
- Completed assessments clear the saved in-progress data.

No Firestore rules changes are required.

Important:
Resume across days works on the same browser/device while Firebase anonymous authentication remains stored.
Clearing browser site data, using incognito, or switching devices may change the anonymous UID and prevent access to the old progress.
